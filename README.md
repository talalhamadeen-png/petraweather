# فريق طقس البتراء 🌤️

موقع إلكتروني ميداني متكامل لرصد حالة الطقس في مدينة البتراء الأثرية ومحيطها (وادي موسى) لحظة بلحظة.

### مميزات الموقع:
- **نشرة جوية ميدانية** كتابية متجددة.
- **نظام الإنذار المبكر** (أمطار، رياح قوية، برق ورعد، ضباب).
- **درجات الحرارة الحالية والعظمى والصغرى** لليوم.
- **توقعات الـ 24 ساعة** (ساعة بساعة).
- **رادار الأمطار المباشر** ورادار الغيوم والسحب.
- **توقعات النماذج العددية العالمية** (الأوروبي ECMWF، GFS، كوزمو COSMO، الكندي CMC).
- **توقعات الطقس لمدة 10 أيام** قادمة.

### طريقة التشغيل:
الموقع مبني بلغة HTML5 و CSS3 وجافاسكريبت صافية، ويعمل مباشرة عبر متصفحات الإنترنت ودون الحاجة لأي إعدادات معقدة.
